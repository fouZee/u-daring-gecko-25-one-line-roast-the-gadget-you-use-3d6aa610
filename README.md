One-line roast for make.fun's "One-Line Roast: The Gadget You Use Every Day" bounty — a single original line roasting the smart fridge, delivered by a small deterministic program.

## The roast

> My smart fridge texts me that I'm out of milk while I'm standing in front of it holding the milk, wondering which one of us is the appliance.

The setup is a concrete, specific behaviour: the fridge texts you that you're out of milk while you're standing in front of it holding the milk. The punchline turns the roast back on the owner — at that point it's genuinely unclear which one of them is the appliance.

## Run it

```sh
node main.ts
```

This writes the roast to `/output/entry.txt` (set `OUTPUT_DIR` to write elsewhere, e.g. `OUTPUT_DIR=./output node main.ts`). Node 22+ runs the TypeScript directly; no dependencies, no network, deterministic output.
